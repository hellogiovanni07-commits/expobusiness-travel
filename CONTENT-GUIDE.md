# Content guide

How the ExpoBusiness site is organised, where each piece of information lives, and how to update it.
Rule of thumb: **change the data file, then run `python build.py`.** Never edit the same fact in two places.

## 1. Site map (page categories)

| Category | Page | File | Built from |
|---|---|---|---|
| Home | Home | `index.html` | hand-written; also the source of the shared nav, footer and icons |
| Plan & book | 2027 itineraries (catalogue with filters) | `itineraries.html` | `data/itineraries-data.js` |
| Plan & book | Request a quotation | `inquiry.html` | trip list from `data/itineraries-data.js`; `?expo=` and `?trip=` prefill |
| Expo guides | China guide (planner, Canton Fair, visa and timing) | `china-expos.html` | `data/expo-china.js`, `data/site-config.js` |
| Expo guides | Expo articles (hub: every 2027 show, month by month) | `world-expos.html` | `data/expo-china.js` + `data/expo-world.js` via `expos.js` |
| Expo guides | One expo article | `event.html?e=<slug>` | the expo's entry in either data file |
| Expo guides | Industries hub + 8 industry pages | `industries.html`, `industry-*.html` | generated by `build-industries.py` |
| Services | Services | `services.html` | hand-written |
| Services | China visa | `visa.html` | hand-written |
| Internal | Brand kit (logo, stationery, social, print) | `brand-kit/index.html` | standalone, not linked from the site, blocked in `robots.txt` |

Navigation follows the same order: Home · Itineraries · China guide · Expo articles · Industries · Services · Visa · Request a quotation.

## 2. Where information lives

All data files are in `assets/js/data/`.

| What | File | Notes |
|---|---|---|
| Phone, email, address, hours, social links, DOT and registration numbers | `site-config.js` | Must stay valid JSON after `window.SITE =`. Values in `[brackets]` show as placeholders. |
| Canton Fair session dates (both 2027 sessions, all phases) | `site-config.js` → `canton.sessions` | Feeds itineraries, countdowns, the schedule table, industry pages, the chatbot and the China guide. Set `"expected": false` once the organiser confirms. |
| China and Hong Kong expos (planner + articles) | `expo-china.js` → `EXPO_CN` | One object per show. |
| Expos outside China (articles) | `expo-world.js` → `EXPO_WORLD` | One object per show, one per line. |
| Ready-made trips (Canton Fair phases + China expo trips) | `itineraries-data.js` → `ITINERARIES` | Departures, inclusions, day plans, event banners. |
| Visa and planning notes, Canton key numbers | `expo-china.js` → `CN_BRIEF` | Shown on the China guide. |
| Chatbot answers | `assets/js/chatbot.js` → `KB` | Dates and contact answers read `site-config.js` automatically. |
| Industry page copy | `build-industries.py` → `INDUSTRIES` | Rerun the build after editing. |

## 3. Expo entry fields

```js
{ name: "Full official name", short: "Short name", city: "Guangzhou", country: "China",   // country only in expo-world.js
  region: "Europe",                         // expo-world.js only: East Asia, Southeast Asia, South Asia, Middle East, Europe, North America
  venue: "Canton Fair Complex, Pazhou", dates_2027: "18–21 Mar 2027", month: "2027-03",
  dates_status: "confirmed" | "expected",   // confirmed = checked on the organiser's site
  frequency: "Annual", organiser: "…", sectors: "Comma, separated, sectors",
  industries: ["furniture", "horeca"],      // electronics machinery lighting construction furniture horeca fashion retail food auto beauty medical
  why: "One sentence: why a Philippine company goes.", url: "https://organiser-site" }
```

The article URL is made from `short` (for example `short: "CIFF Guangzhou"` → `event.html?e=ciff-guangzhou`). Changing `short` changes the URL, so avoid renaming published shows.

## 4. Common updates

**Add an expo.** Add one entry to `expo-china.js` (China/Hong Kong) or `expo-world.js` (elsewhere), run `python build.py`. The show appears in the planner (China list), on Expo articles, gets its own article and is added to `sitemap.xml`.

**The organiser confirmed dates.** Edit `dates_2027`, set `dates_status: "confirmed"`. For the Canton Fair edit `site-config.js` → `canton.sessions` and set `"expected": false`.

**Contact details arrive.** Replace the bracketed values in `site-config.js`, run `python build.py`. Footer, inquiry page, chatbot and brand kit update.

**Add a ready-made trip.** Add it in `itineraries-data.js` with the `CANTON(...)` or `E({...})` helper. Articles link to a trip automatically when its `short` matches the expo's `short`.

**Change the nav or footer.** Edit them in `index.html` only, then run the build.

**New photo.** Article photos are picked by the show's first industry in `assets/js/expos.js` → `PHOTO`.

## 5. Build and publish

```
python build.py
```

Runs the industry builder, layout sync, SEO tags and sitemap, and bumps the `?v=` cache version. Check pages locally at `http://localhost:5210/`, then publish the folder (GitHub Pages) when you approve.

## 6. Folder structure

```
index.html … event.html        pages (one per route)
assets/css/site.css            tokens, nav, footer, buttons, chatbot, planner
assets/css/pages.css           inner-page heroes and sections
assets/css/home.css            home + Canton Fair calendar module
assets/css/articles.css        Expo articles hub + article
assets/js/data/                ALL content data (edit here)
assets/js/site.js              shared behaviour (nav, reveals, CTA stubs)
assets/js/expos.js             combined expo list + slugs, categories, photos
assets/js/articles.js          Expo articles hub
assets/js/article.js           one expo article
assets/js/planner.js           map + month planner
assets/js/fair-calendar.js     Canton Fair hall, countdown, timeline, table
build.py, build-industries.py, sync-layout.py, seo-meta.py   build steps
brand-kit/                     brand materials (internal)
```
